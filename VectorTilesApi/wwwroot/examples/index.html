Open Data Hub Geo API Examples

Check out this Examples on how to use the Open Data Hub Geo Api

Core Files

  • css/style.css Stylesheet
  • js/config.js Configuration
  • js/vector-tile-map.js Library for consuming Open Data Hub Geo API

General Examples

  • Get All Accommodations Clustered Display all Accommodations with clustering enabled.
  • Get Accommodations by passing Ids Display Accommodations by passing a list of Ids.
  • Get All Accommodations disable Clusters Display all Accommodations with clustering disabled
  • Get All Announcements with Points only Display Announcements with clustering enabled showing only the points.
  • Get All Announcements with Points and Tracks Display Announcements with clustering enabled showing points and tracks.
  • LTS Pois displaying as Points Display all Points of Interest with source 'lts' clustering enabled.
  • Show all Skiarea Points and Tracks CURRENTLY NOT WORKING TO FIX.
  • Urban Greens Show Only Points Display all Urbangreens with Points only and clustering enabled (heavy about 300k of data).
  • Urban Greens Show only Tracks Display all Urbangreens with Tracks (very heavy about 300k of data).
  • Show all Wineries with Clustering disabled Display all Wineries and disable clustering.
  • Show all Wineries clustered with custom JsonB Selector Display all Wineries clustered with a custom JsonB Selector (include fields Detail.de.Title, Detail.de.BaseText directly in the Vector Tiles).

Digiway Examples

  • Announcements Hike Closure Trails of Trento Displays all Hike Closures in the Province of TN by dataprovider zoho.
  • Announcements Hike Closure Trails of Austria Displays all Hike Closures in Austria by Dataprovider tirol.mapservices.eu. Tracks and Points are displayed, tracks at zoomlevel 12.
  • Get All Data with Source civis.geoserver display as Points Display all Data with source civis.geoserver, cluster it and display Points only.
  • Get all Data with Source givis.geoserver of Type Cycleways and Display Points and Tracks on a certain zoom level Display all Data with Source givis.geoserver of Type Cycleways cluster the Points and show Tracks on a certain zoom level (12).
  • Get all Data with Source givis.geoserver of Type Hikingtrails and Display Points and Tracks on a certain zoom level Display all Data with Source givis.geoserver of Type Hikingtrails cluster the Points and show Tracks on a certain zoom level (10).
  • Get all Data with Source givis.geoserver of Type IntermunicipalCyclingRoutes and Display Points and Tracks on a certain zoom level Display all Data with Source givis.geoserver of Type Intermunicipality Cycling Roads cluster the Points and show Tracks on a certain zoom level (10).
  • Get all Data with Source givis.geoserver of Type Montainbike Routes and Display Points and Tracks on a certain zoom level Display all Data with Source givis.geoserver of Type Mountain Bike Routes cluster the Points and show Tracks on a certain zoom level (10).
  • Get all Data with Source dservices3.arcgis.com as Points Display all data with Source dservices3.arcgis.com as Points only with clustering enabled.
  • Get all Accessible Trails Data with Source dservices3.arcgis.com Display all data with Source dservices3.arcgis.com of type Accessible trails as Points only with clustering enabled.
  • Get all Data with Source dservices3.arcgis.com of type Cycling Tirol as Points Display all data with Source dservices3.arcgis.com of type Cycling Tirol as Points only with clustering enabled.
  • Get all Data with Source siatTN of Type Cycleways Displays all Data with Source siatTN of Type Cycleways showing points and tracks on zoomlevel 12.
  • Get all Data with Source siatTN of Type Mountainbike Displays all Data with Source siatTN of Type Mountainbike showing points and tracks on zoomlevel 12.
  • Get all Data with Source siatTN of Type Hiking Trails Displays all Data with Source siatTN of Type Hiking Trails showing points and tracks on zoomlevel 12.
  • (WIP) Get all Data with Source euregio.routes (~300k of records) work in progress.
  • (WIP) Get all Data with Source euregio.roadnetwork (~300k of records) work in progress.
